# 05 UI, Accessibility, And Localization

- Use existing shell, form, table, modal, and responsive patterns.
- Every interactive control must be keyboard reachable and have an accessible name.
- Preserve visible focus, correct semantic elements, and modal focus behavior.
- Destructive or irreversible actions require explicit confirmation and pending-state protection.
- Data views must handle loading, empty, error, refreshing, and permission-denied states.
- Mobile layouts must respect safe areas and avoid horizontal content loss.

All user-visible text belongs in `src/i18n/locales/en.json` and `zh-CN.json`. Update both catalogs in the same change, keep placeholders aligned, and add or update message tests. Do not place explanatory comments or raw backend error details in the UI.
